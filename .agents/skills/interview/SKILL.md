# interview

사용자가 담당자 AI(메신저)에게 직접 물을 질문을 준비한다. 너는 질문을 만들고, 답을 TASK.md에 정리한다.

## 순서
1. 과제 README와 자료 파일명·열 이름만 본다(`head -3`, `wc -l`). 통째로 읽지 않는다.
2. `TASK.md`를 열어 **사실 / 가정 / 열린질문 / 안 할 일 / 완료조건** 초안을 채운다.
3. 열린질문은 `docs/interview.md`의 5단계 순서(맥락 → 입출력 → 규칙·우선순위 → 경계값 → 완료기준)를 따르되, 이 과제에 맞는 것만 **최대 8개**, 한 문장씩.
4. 사용자가 담당자 답을 가져오면: 답을 **사실**로 옮기고, 확인된 가정은 사실로, 새 질문은 열린질문에 추가한다.
5. 가정이 3개 이상이면 멈추고 "담당자에게 물어볼 것"을 먼저 올린다.

## 질문을 잘 만드는 기준
- "뭘 만들면 되나요" X → "정원 초과 시 누가 우선인가요" O. 업무를 짚어서 묻는다.
- 경계값은 반드시 포함: 같으면 포함? 동점? 빈 값? 중복?
- 담당자 답변 원문을 복붙하지 않고 요약한다.
