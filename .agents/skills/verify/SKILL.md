# verify

"초록불이 거짓말하는" 상황을 막는다. 아무것도 검사하지 않은 통과는 통과가 아니다.

## 순서
1. `python3 -m unittest -v` 실행. 결과 전체가 아니라 **PASS/FAIL 수와 실패 이름**만 보고한다.
2. 테스트가 0개이거나 전부 skip이면 **"미검증"**이라고 명시한다.
3. 완료조건(TASK.md DONE-N)마다 대응 테스트가 있는지 표로 확인한다. 없으면 만든다.
4. **손 검산 1개 이상**: 출력 1행을 입력 원본에서 찾아 대조하거나, 총합·건수를 다른 방법으로 다시 센다.
5. 경계값 케이스(동점·빈 값·중복·정원 초과)를 작은 입력으로 직접 돌려본다.
6. 결과를 `VERIFY.md`에 적는다: 조건 / 테스트 / 결과 / 근거 출력. 약점은 솔직하게.

## 금지
- "테스트 통과했으니 완료" 같은 결론을 근거 없이 쓰지 않는다.
- 통과시키려고 기대값을 바꾸지 않는다. 기대값이 틀렸다고 판단하면 사용자에게 먼저 묻는다.
