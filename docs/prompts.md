# 단계별 Codex 프롬프트 (복붙용)
모델: `/model` → Sol 6.1, reasoning high. 계획은 `/plan` 또는 Shift+Tab.

## S0. 시작 (clone 직후)
```
AGENTS.md를 읽고 이 세션 규칙으로 써. python3 scripts/preflight.py 돌려서 결과 요약해줘.
아직 코드 쓰지 마.
```

## S1. 계약서 작성
```
과제 README와 자료 파일 목록(head/wc만)을 보고 TASK.md의 사실/가정/열린질문/안 할 일/완료조건 초안을 채워.
열린질문은 담당자에게 물을 수 있게 짧은 질문 문장으로. 코드는 쓰지 마.
```

## S2. 담당자 답변 반영
```
담당자 답변: (내 말로 요약해서 붙임)
이걸 TASK.md 사실로 옮기고, 가정 중 확인된 건 사실로, 새로 생긴 질문은 열린질문에 추가해.
```

## S3. 계획
```
/plan
TASK.md 완료조건 기준으로 구현 계획을 세워. 완료조건 1개당 테스트 1개로 매핑하고,
입력→출력이 끝까지 도는 최소 버전(E2E v0)을 1단계로 둬. 파일 구조와 단계별 소요 예상도.
```

## S4. E2E v0
```
계획 1단계(E2E v0)만 구현해. 표준 라이브러리만. 돌려서 출력 파일 첫 5행 보여주고,
입력 건수와 출력 건수가 맞는지 확인해. 결정한 게 있으면 DECISIONS.md에 한 줄 추가.
```

## S5. 완료조건 하나씩
```
DONE-N 구현해. 테스트 먼저 쓰고(test_done_n), 구현하고, python3 -m unittest -v 결과 보여줘.
통과하면 git add -A && git commit -m "DONE-N: (한국어 한 줄)".
```

## S6. AI 답 검산 (의심될 때)
```
방금 결과에서 (특정 행/숫자)가 맞는지 입력 원본에서 근거 행을 찾아서 보여줘.
다른 방법(예: 수동 집계)으로 같은 값이 나오는지 교차 확인해.
```

## S7. 동결 후 (140분)
```
기능 추가 금지. 전체 테스트 돌리고 실패 있으면 고쳐. VERIFY.md 채우고,
알려진 약점 3개를 솔직하게 적어. DECISIONS.md 빠진 결정 있으면 보완.
```
