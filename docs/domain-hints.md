# 사전체험 화면 힌트 (11/5) — 식사 복지 · 재충전(휴가)
10/31은 사전체험에 나온 통근버스가 실제 과제였다. 이번 체험 화면은 아래 내용. **과제 자료와 담당자 답이 항상 우선.** 여기 적은 건 "물어볼 거리"와 "테스트로 만들 엣지"다. 규칙을 여기서 추측해 박지 않는다.

## 화면에 있던 사실
- 식사: 조식~야식, 이천캠퍼스 식당 8개(R&D, SKY, 복지관, P&T4, 중앙식당, 청운 식당, 행복 1·2), 한·양·중·일식·피자·버거·분식, **매월 4주차 목요일 특식**
- 재충전: **Happy Friday 월 1회 금요일(두 번째 주)**, **장기근속 휴가 5년마다 10일, 10년마다 3주**, **연차 15일 외 휴가 6일 추가, 최초 1년 초과 근속 연수 2년당 1일 유급휴가**

## 예상 과제 모양 (추정)
- 휴가 계산기: 입사일 → 올해 연차·추가휴가·장기근속 휴가·Happy Friday 날짜
- 근무·휴가 캘린더: 특정 월의 Happy Friday, 특식일, 공휴일 겹침
- 식당 추천·혼잡도 분산: 식당별 메뉴·운영시간·인원 데이터 → 배정/추천
- 조합형: 근무조(주간·야간) + 식사 시간대 + 휴가

## 담당자에게 물을 것 (경계값 = 숨은 조건 후보)
**날짜 정의**
- "두 번째 주 금요일" = 그 달 **두 번째 금요일**인가, **달력 2주차(1일이 속한 주=1주) 금요일**인가? 1일이 토요일인 달은 둘이 다르다
- "4주차 목요일" = 네 번째 목요일인가, 4주차의 목요일인가? 4주차에 목요일이 없거나 다음 달로 넘어가면?
- 그날이 공휴일·명절이면? 다른 날로 옮기나, 건너뛰나? 공휴일 목록은 어디서 받나(네트워크 없음 → 자료로 달라고 한다)
- 주의 시작은 월요일? 일요일?

**연차·휴가 계산**
- 기준일: 입사일 기준인가, 회계연도(1/1) 기준인가?
- 1년 미만 입사자는? (월 1일씩 생기나?) 입사 첫해·중간 입사는 비례?
- "최초 1년 초과 근속 연수 2년당 1일": 3년차부터 +1인가? 계산식 예시 2개 받기 (예: 근속 3년·5년·21년이면 각각 몇 일). 상한(25일 등) 있나?
- 추가 6일은 모든 사람? 연차와 합산해서 보여주나 따로?
- 장기근속: 정확히 5·10·15·20년 되는 해에만? **10년째엔 10일+3주 둘 다인가, 3주만인가?** 15년은 10일? 20년은?
- "3주" = 근무일 15일? 달력 21일? 
- 2월 29일 입사자의 기념일, 휴직·육아휴직 기간은 근속에서 빼나?
- 반차·시간 단위 사용, 이월·소멸 있나?

**식사**
- 야식은 야간조만? 조식·중식·석식·야식 시간대 경계(같은 시각이면 어디)?
- 식당 정원·혼잡 기준, 8개 식당 위치·운영 시간 데이터 있나?
- 특식일이 공휴일이면?

## 시간대 함정 (환경이 UTC)
- 날짜 계산은 `datetime.date`로만. `datetime.now()` 쓰지 말고 기준일을 입력으로 받는다
- 요일은 `date.weekday()` (월=0 … 금=4). n번째 금요일 함수와 n주차 금요일 함수를 **둘 다** 만들어 두고 담당자 답에 따라 고른다

## 테스트로 만들 엣지
- 1일이 금요일인 달 / 토요일인 달의 Happy Friday
- 다섯 번째 목요일이 있는 달, 4주차 목요일이 다음 달로 넘어가는 달
- 입사 정확히 1년·3년·5년·10년 되는 날 전날·당일
- 2/29 입사, 12/31 입사, 연도 경계
- 근속 10년(장기근속 겹침), 근속 21년 이상(상한)
