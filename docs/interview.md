# 담당자 AI 인터뷰 순서
오른쪽 메신저의 담당자 AI에게 **내가 직접** 묻는다. "뭘 만들면 되나요"처럼 막연하게 묻지 말고 업무를 짚어서 묻는다.
답은 받을 때마다 TASK.md에 옮겨 적는다. 질문은 한 번에 2~3개씩.

## 1단계: 업무 맥락 (5분)
1. 이 결과물은 **누가** 쓰나요? (본인 / 팀 / 임직원 전체)
2. **지금은** 이 일을 어떻게 하고 계세요? (엑셀 수작업? 어디서 제일 시간이 걸리나요?)
3. 이번 과제의 **최종 결과물 형태**는 뭔가요? (CSV 파일 / 화면 / 표 / 보고서)
4. **언제 쓰나요**? (매일 / 매주 / 신청 마감 후 1회)

## 2단계: 입력·출력 (5분)
5. 입력 파일은 주신 게 전부인가요? 열 의미가 헷갈리는 게 있는데 OOO 열은 무슨 뜻인가요?
6. 출력에 **꼭 들어가야 하는 열**과 순서가 있나요? 예시 한 줄 보여주실 수 있나요?
7. 기준일(오늘)은 언제로 잡나요?

## 3단계: 규칙·우선순위 (10분) ← 숨은 조건이 여기서 나온다
8. 여러 명이 겹치면(정원 초과, 같은 시간대) **누가 우선**인가요?
9. **동점이면** 어떻게 하나요?
10. **예외**가 있나요? (임원, 장애, 특정 부서, 사전 승인자)
11. 안 되는 사람은 **대기**로 두나요, **탈락**인가요? 대기 순서는?
12. 신청 **취소/변경**은 반영하나요?

## 4단계: 경계값 (5분)
13. 정원이 10명일 때 **딱 10명째**는 들어가나요?
14. 날짜 "~까지"는 그날 **포함**인가요?
15. 값이 **비어 있거나** 형식이 다른 행은 버리나요, 오류로 표시하나요?
16. 같은 사람이 **중복 신청**하면?

## 5단계: 완료 기준 (3분)
17. 결과를 보고 **"됐다"고 판단하는 기준**이 뭔가요? (몇 건 맞으면 / 어떤 화면이 보이면)
18. 꼭 있었으면 하는 것 1개, 없어도 되는 것 1개를 꼽는다면?

## 중간에 다시 묻기
- 구현 중 TASK.md "가정"이 생기면 바로 묻는다. 가정 3개 이상 쌓이면 멈추고 질문한다.
- 담당자 답변은 메신저에 남으니 복붙하지 말고 **내 말로 TASK.md에 요약**한다.
